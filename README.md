# cornellpdp-ts
 
website of pi delta psi at cornell university kappa chapter

built with next.js and react.js and without tailwind so your eyes suffer less

Requires Node.js 26.x and Yarn.

to run locally (with nvm installed)
```
nvm install
nvm use
yarn
yarn dev
```

For Vercel deployments, `package.json` specifies Node.js `26.x`. Set
Project Settings → Build and Deployment → Node.js Version to `26.x` as well,
then redeploy to apply the runtime change.
